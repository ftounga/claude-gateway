Étape 2 — Le build

Comment le code devient une image déployable

  • Déclenché à chaque push sur main — preuve : .github/workflows/backend.yml:12
  • Compilation puis empaquetage en image conteneur (Docker) — backend/Dockerfile
  • L'image est étiquetée par le hash du commit — staging-<sha>
  • Prérequis appris ce jour : contexte = racine du dépôt, clé de signature du runner
