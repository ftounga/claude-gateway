report_problem Ce qui ne s'arrête pas

Le runner continue de tourner sur la machine. Ce geste agit sur la passerelle, pas sur votre poste : le programme va tenter de se reconnecter, et sera refusé — son jeton n'existe plus. Rien ne s'arrêtera de soi-même dans le terminal où il tourne.

terminal Pour l'arrêter vraiment, sur la machine

  • Dans le terminal où le runner tourne : Ctrl-C.
  • Ce terminal est fermé — macOS, Linux : pkill -f claude-runner.jar
  • Sous Windows : taskkill /F /IM java.exe, ou le Gestionnaire des tâches.

Cette application ne peut pas arrêter un programme sur votre machine, et ne le fera jamais.
