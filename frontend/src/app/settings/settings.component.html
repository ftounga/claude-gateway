Compte GitHub

Enregistrez un jeton d'accès personnel GitHub pour que l'Atelier travaille directement sur vos dépôts. Le jeton est vérifié auprès de GitHub, chiffré, jamais affiché en clair, et n'entre jamais dans le bac à sable de l'agent.

Un jeton fine-grained limité aux dépôts concernés est recommandé : portée Contents : lecture pour cloner, lecture et écriture pour pousser une branche. Les droits exacts se constatent à l'usage — GitHub ne permet pas de les vérifier à l'avance.
