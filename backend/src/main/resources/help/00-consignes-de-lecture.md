# Comment lire cette documentation

Ce document est la **documentation d'aide de Claude Portal**, destinée aux personnes qui utilisent
le produit. Elle décrit ce que fait l'application, comment installer et connecter une machine, et
que faire quand un message d'erreur apparaît.

Ce qu'elle **ne contient pas**, et qu'aucune réponse ne doit inventer :

- le contenu des projets, fichiers ou conversations d'un utilisateur ;
- des tarifs, dates ou engagements qui ne sont pas écrits ici ;
- des options de ligne de commande, des chemins ou des noms de fichiers qui ne sont pas écrits ici.

Si une question n'a pas sa réponse dans les pages qui suivent, la seule réponse correcte est de
dire que la documentation ne le précise pas.

Le nom du produit est **Claude Portal**. Son adresse est `https://portal.ng-itconsulting.com`.
Le programme installé sur la machine de l'utilisateur s'appelle le **runner** (`claude-runner`).
